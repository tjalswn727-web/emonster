# 감정 몬스터 주식회사 (Emotion Monsters Inc.)

특수교육대상학생 사회정서학습(SEL) 및 실시간 감정 체크인 · SOS 알림 지원 웹 애플리케이션의 프리뷰(v1) 구현입니다. `PRD v2.0`을 기반으로 제작되었습니다.

## 실행 방법

```bash
npm install
npm run dev
```

## 구현된 화면

- **시작화면** — 사원증 만들기(온보딩) / 출근하기(로그인) / 교사 관리자 모드 진입
- **온보딩** — 안내 몬스터 소개 → 몬스터 알(0단계) 선택 → 이름/4자리 비밀번호 입력 → 사원증 발급
- **로그인** — 이름/비밀번호 확인 후 출근 도장 도킹 애니메이션
- **메인 대시보드(로비)** — 몬스터 진화 상태, 보유 감정 에너지(pt), 획득 배율, 4대 메뉴
- **감정 에너지 수집하기** — 1단계 어휘 매칭 + 2단계 상황별 반응 작성
- **주식회사 일지** — 9개 카테고리 감정 어휘(각 10개) 선택 + 1~10단계 온도계 + 일지 작성
- **감정 에너지 관리하기** — 4색 구역(Zones of Regulation) 1-Tap 체크인, 빨강 구역 SOS 알림, 감정 다스리기 도구 3종(10초 세기 / 심호흡하기 / 긍정 카드 뒤집기, 1시간 쿨다운 +5pt)
- **에너지 매점 & 진화** — 보상 상품 구매, 1~4단계 진화의 돌 구매 시 즉시 진화 + 획득 배율 증가
- **교사 관리 탭** — 학생별 포인트 수동 지급/차감, 매점 상품 설정, 오늘의 감정 체크인 타임라인, 위기 학생(빨강 2회 이상/미해결 SOS) 자동 강조

## 몬스터 종

진화 단계는 **0~4단계(알 → 유아 → 어린이 → 청소년 → 성인)** 5단계이며, 아래 4종 모두 실제 원본 아트로 구현되어 있습니다 (`src/assets/monsters/`, `src/components/MonsterArt.tsx`).

| 종 | 이름 | 컨셉 |
| :--- | :--- | :--- |
| `leaf` | 새싹몬스터 | 포근포근 잎사귀 친구 |
| `crab` | 집게몬스터 | 단단하고 야무진 자물쇠 친구 |
| `butterfly` | 나비몬스터 | 반짝반짝 빛나는 나비 친구 |
| `star` | 별빛몬스터 | 신비로운 밤하늘 친구 |

새 종을 추가하려면 `src/assets/monsters/<species>/stage-{0..4}-*.png` 5장을 넣고 `MonsterArt.tsx`의 `SPECIES_ART`, `data/monsters.ts`의 `MONSTER_SPECIES`에 항목을 추가하면 됩니다. 아트가 아직 없는 종은 `MonsterArt`가 자동으로 절차적 SVG로 대체 표시합니다.

## 데이터 저장 방식 (프리뷰 한정)

현재는 구글 스프레드시트 연동 전 단계로, 모든 데이터(학생 계정, 감정 일지, 무드 체크인, 구매 내역, 매점 상품)는 브라우저 `localStorage`에 저장되는 mock 스토어(`src/store/useStore.ts`, Zustand)로 동작합니다. 같은 브라우저를 학생/교사가 함께 쓰면 세션이 서로 덮어쓸 수 있으니, 실제 사용 시에는 학생별/교사별로 별도 기기 또는 브라우저 프로필을 권장합니다. 교사 관리자 비밀번호는 데모용 고정값 `0000`입니다.

향후 개발 단계에서 구글 스프레드시트 3개 시트(감정 일지 / 실시간 기분 / 학생 종합 통계) 연동 및 실제 인증/서버 저장으로 교체할 예정입니다.
